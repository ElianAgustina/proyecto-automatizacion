# Proyecto - Automatización Web

Proyecto de automatización de pruebas web utilizando **Python, Selenium y Pytest**.

## Instalación

```bash
python -m pip install selenium pytest pytest-html
```

## Ejecutar pruebas

```bash
python -m pytest
```

O una prueba específica:

```bash
python -m pytest test_login.py
```

## Reporte

El reporte HTML se genera automáticamente en:

```text
reports/reporte.html
```
